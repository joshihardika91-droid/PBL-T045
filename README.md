PROJECT TITLE- Hostel-Mate 
# Description
The project is designed to reduce the manual work of hostel record management with a special focus on students specific needs. It simplifies tasks like attendance management,
room allocation, leave application handling, complaint handling and fees handling. This system will be a platform to store and access information related to hostel
efficiently.
# Problem Statement
In hostels many tasks are still managed manually, which makes it difficult to handle student records. Attendance ,room allocation ,leave application ,fees and complaints can take lot of time
and many lead to mistakes. Students may also face delays in getting help or information. Therefore, HostelMate aims to make these hostel Activities easier,faster and more organised.
# Objectives
Key Objective: To develop a smart and efficient system that simplifies hostel management and reduces manual work.

 # Proposed Modules
1.User Authentication Module: Admin authorizes and registers new users,existing users can log in their dashboard.
2.Fee Module: Manages the tasks related to fee management and handling fees records.
3.Student Module: Links the functions related to students like leave application, retrieving hostel information regarding mess and other updates and raising complaints.
